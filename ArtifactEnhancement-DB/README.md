# Artifact Enhancement for Java Android Studio Project

A program that allows the user to manage customers and provides basic in order listing as well as full-text searching.
-----------------------------------------------------

Original source code credited to Shad David Sluiter of FreeCodeCamp: https://www.youtube.com/watch?v=312RhjfetP8

-----------------------------------------------------

To add a customer, first navigate to the "Customers" window. Then enter the customers name, age, and optionally use the switch to set their active status. Then press the add button and the customer list will update and display the customer below the input boxes.

To remove a customer, first navigate to the "Customers" window. Then click on the customer's cell in the customer list displayed below the text boxes and an alert box should pop up asking you to confirm deletion. Choose delete to remove the customer from the database or cancel to leave the customer in the database.

3. Search for Customer

<img src="https://github.com/user-attachments/assets/4ace368a-10ae-45e7-9319-34aea7770b80" width="30%"/>

To search for a customer, first navigate to the "Search" window. Then enter a query into the text field. As can be seen from the example, even active status can be searched. Press the search button to search for the query, no results will be returned if there are none to be found. Press the clear button to clear all search results as well as the text query.
