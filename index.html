Professional Self-Assessment

Through my time at SNHU, there has been a concerted effort to instill professionalism and develop skills applicable to a professional environment. Some of these skills include an understanding of SDLC/DevSecOps and their implementation, system analysis, Git and version control, secure coding standards, principles of OOP, interfacing with APIs, vulnerability assessments, basic reverse engineering (using tools such as Ghidra and GDB), assembly, and familiarity with a wide range of programming languages. There are many examples from my time at SNHU that I could reference, but two (outside of the artifact enhancements) are particularly representative.

Security Policy Project: The first example is a security policy developed for a fictional software company. In this project, I created a secure coding standard and provided guidance for automating tasks in a DevSecOps pipeline. This was the most comprehensive project and best prepared me for entering a professional development environment.

System Analysis and Design Project: The second example is a system analysis and design project for another fictional software company. Undertaken earlier in my studies, this project demonstrated the foundational work required for designing a system, including constraints, functional and non-functional requirements, accuracy and precision, adaptability, security, user interfaces, system assumptions and limitations, and a Gantt chart for workflow. Ultimately, this work was presented in a PowerPoint presentation. These two examples, while not involving any code execution, were crucial for gaining a deeper understanding of computer science.

Collaborating in a team environment and communicating with stakeholders are also essential aspects of a career in computer science. Clear communication is important in both contexts. This includes being concise and clear in code commenting, thorough and accurate in producing documentation and diagrams, and effective in verbal and written communication. All audiences should be considered, and a communication style that is easily understood by everyone should be used.
