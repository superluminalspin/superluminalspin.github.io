# Artifact enhancement for C++ Binary Search Tree (BST) implementation

This enhancement contains the following upgrades:

-Refactored helper functions, Binary Search Tree class, and node structure to separate modular header files.

-Implemented the AVL Tree class as the enhancement which self-balances the BST for more efficient operations.

-Implemented unit tests to test modular functionality of new BST and AVL Tree classes

-Used Google Test framework to run timing comparisons between BST and AVL Trees. Further information on tests can be found in the /AVLTests repository.
